How to Play

  • Click a tile adjacent to the empty cell to slide it. Or move the empty cell with WASD / arrows.
  • Tiles in green are already in the correct spot -- but you can still move them!
  • Reach a checkpoint (e.g. 1-20 correct) to trigger a timed event (1:15-3:00).
  • The event generates Threat. Harder events generate more Threat.
  • If you pass the event -- choose a bonus (Time+, Second Chance, Preview, Focus, Stabilizer).
  • If you fail the event -- the boss immediately applies a penalty to the board (teleport empty, swap numbers, scramble zone). No need to defeat it.
  • Final goal: all numbers ordered.
Events: Mini Puzzle · Memory · Sequence · Sort · Find · Corruption
